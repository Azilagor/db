Запросы
1. Получить рейтинг самых популярных маршрутов за прошлый год. Отчёт представить в виде:
Id маршрута; количество пунктов маршрута; сезонность; сложность; число раз, сколько походов было оформлено по данному маршруту; число уникальных туристов, которые проходили маршрут; общее число туристов, включая не уникальные; среднее количество туристов в одном походе; самый популярный инвентарь на данном маршруте.
2. Получить отчет о клиентах, которые более года не участвовали ни в каких турах. Отчет представить в виде:
Id клиента; ФИО клиента; номер телефона; дата последнего участия; общее количество походов, в которых участвовал клиент; количество зимних, весенних, летних, осенних походов, в которых принял участие клиент, представить в виде “1-0-0-4”;
3. Получить статистику тур. походов за предыдущий год по месяцам. Статистику представить в виде:
Номер и название месяца; число походов в этом месяце; время года; общее число тур. походов; общее число участников; общее число уникальных участников; нарастающий итог по количеству участников и количеству походов; ФИО гида, который провел больше всего походов и количество проведенных им походов.
4. Получить географическую информацию о маршрутах, отчет представить в виде:
Id маршрута; общее число точек похода; инфа о первой точке; инфа о последней точке; длина маршрута, подсчитанная на основе координат точек, расстояние между двумя точками определяется как:  ; средняя длина перехода между точка; максимальная и минимальная длина перехода;
5. Получить информацию о пробеге транспорта в соответствии с маршрутами, в которых они участвовали. Отчет представить в виде:
Id транспорта; название транспорта; тип транспорта; дата первого участия в каком-либо походе; дата последнего участия в каком-либо маршруте; средний “простой” транспорта между походами (в днях)l суммарная длина маршрутов, в которых транспорт принимал участие, рассчитанная как в 4 запросе; средний пробег транспорта в год (рассчитывается только по годам, начиная с года, когда транспорт участвовал в каком-либо походе).
